## Session 4 (cont.): Gate-1 implementation audit — the instrument, not the model

- **Audited the GNN for a defect explaining the FAIL. Found none.** Verified correct: seed/label alignment in the loss, class-weight ordering, `subgraph(relabel)` ↔ `x[test_mask]` row order, device placement, dropout train/eval. Extracted `predict_window()` from `evaluate()` so diagnostics score through the *identical* path as the gate runs.
- **Two data facts exonerate the protocol.** **Zero** edges cross the 34/35 cutoff (all 468,710 are within-time-step), so strict-inductive induction drops nothing; mean degree **2.30** (median 2), so fan-out 25 truncates 0.26% of train nodes — sampling ≈ full graph. The protocol isn't the handicap; a degree-2.3 graph whose features already encode one hop is.
- **Prevalence is severely non-stationary:** 30–32 = **20.8%** illicit, 33–34 = **6.3%**, 35–49 = **6.5%**, train overall 11.6%. The HPO sweep validated on 30–34 (16.8%) — the most positive-dense window in the dataset. That, more than the step-43 cliff, explains val F1 0.93 → test 0.68.
- **Built `scripts/diagnose_ell1_inner.py`** (train ≤29, measure 30–34, 35–49 never constructed) to price three hypothesised handicaps: model selection, threshold calibration, rank-transform.
- **All three came back below the noise floor.** Model selection +0.021/+0.029; calibration oracle ceiling +0.031/+0.077 with the two honest transfer folds at **−0.018 and +0.032** (opposite signs, 23/37 illicit); rank-transform +0.030 in one run, +0.004 in a repeat.
- **What broke — the instrument.** Same config, same seed, three repeats **in one process** on CUDA: 0.9151 / 0.9283 / 0.8939, **spread 0.0344**. CPU: identical to 8 dp, spread **0.0**. `seeding.py`'s cuDNN flags never governed PyG's scatter atomics. → **ADR-005 (proposed)**: gate-grade runs on CPU; ≥20 repeats if GPU.
- **Surprised:** my three hypotheses were all smaller than the measurement error, and the ±0.031 "seed variance" in `GATE-ELL1-1.md` is indistinguishable from the 0.034 spread of *identical* repeats — that column is largely run noise. Gate-1 verdict unaffected (0.127 deficit ≈ 4× the floor); its stated precision is not.
- **Tomorrow's first move:** decide ADR-005. If accepted, time one full 40-epoch CPU run on 1–34 (unmeasured — the 5-epoch probe does not extrapolate), then harden `gbe/run/seeding.py`. Handicaps stay closed as *unmeasurable*, not refuted, until the instrument is fixed.
