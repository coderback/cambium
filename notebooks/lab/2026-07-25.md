# 2026-07-25 — Session 5: Gate 3 (defending ablations) + the local-94 experiment. ELL-1 closes.

- **GATE 3 PASSED** (signed, dated). Stage 1 of ADR-006: 5 arms × 8 seeds, deterministic, `dirty=false`, 40 rows. All three gated clauses positive and resolvable on illicit-F1 vs real **0.6629 ± 0.0702** — scrambled **0.5611** (+0.1017, p=0.0041), random **0.5885** (+0.0744, p=0.0329), no-edges **0.5928** (+0.0700, p=0.0329). Survives the *exact* Welch critical values (2.16–2.23×SE, not just the ADR's 2.00×), so it doesn't rest on the one loosening ADR-006 admits to. No stage-2 top-up triggered.
- **The reported arm is the science.** `config` (every node's degree preserved, only wiring randomised) falls to **0.5687** — level with full scramble, *below* both random-graph and no-graph. Preserving degree rescues nothing → message passing reads something features 94–164 don't encode. This is the claim that survives the standing objection to Elliptic, and it was deliberately **not** a gate input.
- **Non-monotonic ordering nobody pre-registered:** no-edges (0.5928) and random (0.5885) both score *above* scrambled (0.5611) and config (0.5687). A plausible-but-wrong graph hurts more than no graph — message passing confidently aggregates misleading neighbours. The arms are not a severity ladder.
- **Local-94 experiment (doc §3, "the sharpest experiment this model can run") splits both ways.** Deleting all 71 hand-built one-hop aggregates costs the GNN **nothing measurable**: F1 +0.0636 vs 2×SE_diff 0.0795 (unresolvable, p=0.13), AUC **−0.0033** (p=0.41, tight SEs). So message passing *did* replace the manual aggregation. It still doesn't approach the tree: GNN-local-94 **0.5992** vs RF-165 **0.8068**, gap −0.2076.
- **Sharpest single number of the session:** GNN-on-94-local-features matches RF-on-all-165 on **recall** — 0.7244 vs 0.7231 (RF ±0.0027) — while precision is **0.53 vs 0.91**. The GNN isn't missing illicit transactions; it's flagging licit ones. And the aggregates don't add information to the GNN, they *move its operating point*: precision 0.53→0.73, recall 0.72→0.61, AUC flat.
- **Carry to DGF-1:** ROC-AUC badly understates this. The arms look close on AUC (0.923 vs 0.939) while differing 0.38 in precision at matched recall — ROC-vs-PR divergence at 6.5% prevalence. **DGF-1's Gate 1 is specified on AUC** and could clear a bar that hides exactly this failure mode. Decide before that gate is written.
- **Seed variance is real, not run noise.** Deterministic real arm ±0.0702 at n=8 vs ±0.0790 nondeterministic at n=6 — determinism removed only a sliver. GraphSAGE genuinely is that seed-sensitive on this graph; the 3-seed convention in Gates 0/1 was under-powered for reasons beyond ADR-005.
