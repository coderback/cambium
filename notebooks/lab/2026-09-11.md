# 2026-09-11 — Session 12: EXTRACT started; ADR-011 (DGF-1 temporal split) drafted, reviewed, accepted

- **Picked back up after six weeks.** Environment still matches the ADR-008 pin, 89 tests green, registry unchanged at 103 rows (nothing written today). Branch `feat/extract-dgf1-phase0` off `0b73eb5`.
- **Finding: the core's temporal guards only reason about node times.** That was fine on Elliptic, where all 468,710 edges sit within one step. On DGraph, the node-induced train graph at 369 admits **399,366** post-cutoff edges that `assert_no_temporal_leakage` cannot see. ELL-1's window-only eval would also isolate **36.66%** of labelled test nodes.
- **ADR-011 accepted:**
  - node time = earliest incident edge;
  - windows 1–369 / 370–481 / 482–821, from a 70/85 labelled-count rule fixed before measuring, with roles matched to the official split (every run trains on ≤369);
  - training graph by edge date; scoring view = the graph as of the window's end;
  - **parity floor** gated; window-only and first-appearance rows reported;
  - `edge_time` becomes a **required** input to `gbe.eval` (ELL-1's derived dates `torch.equal` to the current path at 29 and 34).
- **Two review rounds.** 11 defects in my own draft, 3 serious: the eval choice favoured the GNN undisclosed, the guard was opt-in, and there was no fit-on-train rule. A literature agent and a red-team agent informed the three open decisions; the red-team added 4 more defects.
- **Integrity slip, mine:** the red-team prompt didn't forbid held-out labels, and it computed fraud-vs-normal degree on the test window. Recorded verbatim in ADR-011's Disclosure. Rule from then on: any change to clauses 2–4 must make Gate 1 harder for the GNN, or rest on label-free evidence.
- **Surprised:** three independent arguments converged on role-matching, and one was a measurement nobody expected. The train view as of 369 matches the test view as of 821 (median age 219 vs 202, mean degree 1.87 vs 1.89); training on ≤481 would have broken that (298, 2.31).
