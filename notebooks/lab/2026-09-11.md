- **Picked back up after six weeks.** Environment still matches the ADR-008 pin, 89 tests green, registry unchanged at 103 rows (nothing written today). Branch `feat/extract-dgf1-phase0` off `0b73eb5`.
- **Finding: the core's temporal guards only reason about node times.** That was fine on Elliptic, where all 468,710 edges sit within one step. On DGraph, the node-induced train graph at 369 admits **399,366** post-cutoff edges that `assert_no_temporal_leakage` cannot see.   - windows 1–369 / 370–481 / 482–821, from a 70/85 labelled-count rule fixed before measuring, with roles matched to the official split (every run trains on ≤369);

  - `edge_time` becomes a **required** input to `gbe.eval` (ELL-1's derived dates `torch.equal` to the current path at 29 and 34).
