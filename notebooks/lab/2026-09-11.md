## Session 19 (2026-09-12): ADR-012 drafted — DGF-1 Gate 1, pre-registered

- **Written blind, and it says so.** No DGF-1 score exists on any window; the floor has never run. Every count and criterion below is fixed before the first number, in ADR-004's full sense. ADR-011's test-window label look is **re-disclosed** here because it bears on this ADR's floor — and it argued *for* parity, which makes Gate 1 harder for the GNN.
- **The structural choice: the rule is pre-registered, the input is measured later.** ADR-007 requires the seed count to come from a pilot on validation, which cannot run yet. So ADR-012 fixes the *mapping* from pilot variance to seed count, and the number becomes mechanical once the pilot exists. Writing the ADR after the pilot would have meant specifying arms, floor and criteria with val numbers in view.
- **Seed-count rule:** the smallest `n` in {8, 12, 16, 20} with `2·SE_diff(n) ≤ ½·Δ_val` for **both** metrics; `n = 20` if none qualifies or the val gap is ≤ 0. The half is a safety factor — a val effect is optimistic, and val users are younger. 8 is the floor (ELL-1 measured 3 to be badly under-powered), 20 the cap, ADR-006's single top-up, no stage 3.
- **Checked the rule is satisfiable before proposing it** (arithmetic, not a measurement): it picks 8 across most regimes, escalates to 16/20 as variance grows against the val gap, and hits the cap only when `s_GNN` exceeds ~½·Δ_val·√20/2. Not vacuous, not trivial. A rule that could only ever return 20 would have been a budget in disguise.
- **Decided the five open items:** the two recency features ratified; the young val window recorded as a caveat the gate file must carry; test-window-only edge type 8 recorded (its column reads 0 for both arms, while the GNN still passes messages over those edges); the floor fully specified (XGBoost 3.4.1, hist, 300 trees, depth 6, `scale_pos_weight`, **no subsampling**); and the floor's determinism **verified by the pilot rather than assumed**, with `s_floor = 0` used only if the rows really are identical.
- **The floor's determinism is a real trade and is stated as one:** it shrinks `SE_diff`, which makes the gate easier, and it is a stronger comparator, which makes it harder. The net is not known and is not claimed.
- **Also fixed:** the retune grid (3 lr × 3 batch, one seed, val only, selected on AUPRC) and **exact-neighbourhood scoring** for every arm and every reported row, so no score depends on an evaluation seed.
- **Enforcement, not intention:** the floor runner already refuses the test window without an accepted pre-registration; ADR-012 requires it to **also** demand a `Stage-1 seeds: N` line, so 482–821 stays closed until the count exists. The GNN runner inherits the same guard.
- **Next (researcher):** accept, reject or send back ADR-012. On acceptance: amend the docs, extend the guard, wire XGBoost into `FLOOR_MODELS`, then the retune and pilot on val — and only then the single test batch.

## Session 20 (2026-09-12): the floor's determinism, re-decided — ADR-012 revised before acceptance

- **The question:** should the gated floor be deterministic (`subsample=1.0`, seed inert, `s_floor = 0`) or stochastic? The first draft pre-committed to deterministic and called it "a genuine trade". A literature agent and a red-team subagent were used, plus my own simulation.
- **Three findings killed the original framing:**
  1. **Manufacturing floor variance would break the seed-count rule, not just raise the bar.** With the floor at 3 seeds and `s_floor = s_GNN`, the bar is **1.91×** the deterministic one at n=8 and **2.77×** at n=20 — but 8→20 seeds moves it only 0.677→0.619·`s_GNN`, because `s_floor/√3` dominates. More GNN seeds would stop buying resolution.
  2. **"Stronger comparator" was an overclaim, probably backwards.** Subsampling is Friedman's regulariser and the big tabular benchmarks *tune* it, so fixing it at 1.0 risks an **undertuned floor — a bias toward the GNN**.
  3. **The variance the gate ignores is the same order as the one it models.** Bouthillier et al. (MLSys 2021): data sampling dominates; seed-only is worth ~2 ideal runs. Paired bootstrap SE of the AUPRC difference ≈ **0.005–0.006** (my simulation and the red-team's, independently) vs a seeds-only SE ≈ **0.007** at `s_GNN`=0.02, n=8.
- **Decision: tune the floor on val with the same 9-config budget as the GNN; determinism becomes a measured outcome, not my prior.** If the winner subsamples, the floor gets the **same seed count as the GNN** (else finding 1 bites).
- **Also repaired in the draft:** the estimand is named (expected performance over seeds, *conditional on this fixed window*); `n_jobs` pinned to a fixed integer because `hist` determinism depends on thread count; and clause 5 gained the ADR-007 carve-out — `Δ_val` is a **power-planning input**, not the cross-window AUPRC comparison ADR-007 forbids.
- **New clause 10: persist per-node score vectors** (~17 MB for the whole gate, gitignored, SHA-256 in the row) and report a **paired stratified bootstrap** CI of the difference, with Boyd et al. (2013) logit intervals per arm. **Option (a):** the criterion stays seeds-only and the bootstrap is reported beside it; if the two disagree, the verdict must say so. Gating on the bootstrap (option b) is stricter but would change the estimand for one gate and break comparability with ELL-1's dated gates — named, not smuggled.
- **Corrected the red-team on one point:** it claimed ROC-AUC would silently drive the seed count because its gaps are smaller. The rule compares each metric against its own `SE_diff`, so it is scale-free; the binding metric is whichever has the worse noise-to-gap ratio. On ELL-1's Gate 3 that was **illicit-F1 (0.69)**, not ROC-AUC (0.32).
- **Integrity note:** the literature subagent **pip-installed `pypdf`** to read a paywalled paper — an environment change mid-EXTRACT. Verified immediately: the freeze diff is `+ pypdf==6.18.1` only, none of ADR-008's five pinned packages moved, `pip check` clean, and the checker still reports "environment matches the pin" with 49/49 rows reproducing. **Subagent prompts must ban installs as well as held-out labels.**
- **Next (researcher):** accept, reject or send back the revised ADR-012.
