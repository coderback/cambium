A graph-ML core held to pre-registered gates, including the one it failed.

cambium is a research codebase: a shared graph-embedding core (the gbe package) with one adapter per dataset. Before a held-out window is opened, the pass condition is written down. Once a gate is signed, its file is never edited, and corrections go in dated errata.

On Elliptic, a random forest won. GraphSAGE reached illicit F1 0.679 against the forest's 0.806, so Gate 1 failed.

On DGraph-Fin, the GNN won by a little. AUPRC 0.0388 against a tree's 0.0318, about 2.6× chance, and far from operationally useful.

Read-only record of committed results. No model runs on this page and no dataset is included. Every number comes from gates/ and experiments/registry.csv at commit f6c415d, and the build fails if a registry row disagrees with its gate file.

Arm (8 seeds)F1PrecisionRecallROC-AUC

Reported, not gated, and run on a dirty tree. Dropping 71 of the 72 aggregates did not resolvably change the GNN's F1. The GNN on local features matches the forest's recall with far lower precision: it finds illicit transactions and also flags many licit ones. AUC looks close while precision does not, which is one reason DGF-1 gates on AUPRC too.

Reproduction after refactoring

When the ELL-1 code moved onto the shared core, ADR-008 replaced "still passes" with a stricter bar: 49 frozen reference rows must reproduce with exact float equality, paired on arm and seed, never retried. A failed gate cannot be re-earned, only reproduced.

Bit-for-bit holds on the recorded environment only. The DGF-1 test rows themselves were never re-run, and ADR-016 has closed their window.

Corrections on the record

Research audit, 2026-10-07

Nothing found overturned a signed verdict or number. It also found that 15 edits breaking a guard left the test suite green, that the statistical rules needed fixing before DGF-1 Gate 3, and that effort after Gate 1 had gone into prose: 35 commits and one run since Gate 0 was signed.

Read the audit

ERRATUM-ELL1-1

Gate 1's "because" blamed the hand-built aggregates. Gate 3 and the local-features diagnostic place the deficit in the neural feature path, so that clause is partly superseded, and the feature range was off by one. The FAILED verdict stands.

Read the erratum

ERRATUM-DGF1-1

Withdraws the sensitivity figures, and later records that the "deterministic" field was true by construction, that some gate facts were typed rather than computed, and that the disclosure of prior looks was incomplete. The PASS and every gated number stand.
